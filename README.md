# ContextGuard

> **Project status: sunset / discontinued.**

BLCCoreStudio has decided to end active development of ContextGuard as part of a deliberate reduction in project count and maintenance load.

ContextGuard explored local redaction of secrets and sensitive project context before sharing files with AI tools. The implementation and Git history are preserved for reference, but **no further feature development or routine maintenance is planned**.

This repository may later be made private or removed after the portfolio cleanup is complete.

## Why development ended

The project is useful as a narrow experiment, but maintaining another standalone security utility would fragment the portfolio and duplicate effort better spent on the smaller maintained project set.

## Historical source

Previous documentation, implementation details and development history remain available through the Git history.
