# Security Policy

ContextGuard is security-sensitive software and is currently in early development.

## Supported versions

No stable release is supported yet. Security fixes are applied to the latest `main` branch during development.

## Reporting a vulnerability

Please do not publish exploit details in a public issue before maintainers have had a reasonable opportunity to investigate.

Use GitHub's private vulnerability reporting feature for this repository when available. If private reporting is unavailable, open a minimal public issue that does not include secrets, working exploit payloads, private data, or sensitive system details, and request a private follow-up channel.

## Scope and limitations

ContextGuard is a defense-in-depth tool. A clean result does not prove that content is safe to share. The current development version uses deterministic local rules and may produce both false positives and false negatives.
